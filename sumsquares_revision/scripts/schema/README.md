[`schema/v0.4.schema.json`](https://github.com/mathlib-initiative/formalization.yaml/blob/99c678e569c7c4c0772db297c5ddd5e4c9b6322e/schema/v0.4.schema.json)
from `mathlib-initiative/formalization.yaml`, pinned at commit
`99c678e569c7c4c0772db297c5ddd5e4c9b6322e`.

The upstream schema is distributed under the Apache License 2.0, reproduced in
`LICENSE`. This license applies to the copied schema, independently of the
project's mathematical source code.

`../check_metadata.py` validates the metadata against this local schema and
requires the version identifier `v0.4`, as the upstream version dispatcher does.
